# AWShorts (AWS Shorts) YouTube Series

# Overview

AWShorts is a YouTube series where I explore different AWS services (primarily around containers) through practical projects I want to work on, with each episode running 10 minutes or less. The goal is to learn and demonstrate my AWS knowledge rather than provide a lesson or tutorial.

This GitHub repository contains the code, configurations and notes for each episode of the *AWShorts* YouTube series.

Each episode folder includes all the files I used during the episode, such as workflows, code, configurations and steps.

The goal is to release an episode every week or every second week on my YouTube channel.
